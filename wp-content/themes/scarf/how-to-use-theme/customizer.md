## نحوه تغییر

1. از پیشخوان وردپرس برو به **نمایش ← سفارشیساز**
2. روی پنل **تنظیمات قالب شال** کلیک کن
3. بخش مورد نظر رو انتخاب کن
4. مقادیر رو تغییر بده
5. **ذخیره و انتشار** رو بزن

---

## فایلهای مرتبط

- `inc/customizer.php` — کد PHP ثبت تنظیمات و خروجی CSS
- `assets/js/customizer-preview.js` — پیشنمایش زنده در سفارشیساز
- `theme.json` — پالت رنگ و تنظیمات بلاک ادیتور

---

## تغییر رنگها از کد

اگه میخوای رنگهای پیشفرض رو عوض کنی (نه از سفارشیساز)، فایل `assets/css/main.css` رو ویرایش کن:

```css
:root {
    --scarf-color-primary: #d83f5f;
    --scarf-color-primary-hover: #c93452;
    --scarf-color-secondary: #19bfd3;
    /* ... بقیه رنگها ... */
}
```

**نکته:** رنگهای CSS custom properties روی تمام سایت اعمال میشن. فقط مقادیر `:root` رو عوض کن.
