# راهنمای سفارشی‌ساز (Customizer)

از مسیر **پیشخوان ← نمایش ← سفارشی‌ساز** میتونی تنظیمات زیر رو تغییر بدی.

## تنظیمات موجود

### 🎨 هویت بصری
| تنظیم | توضیح |
|-------|-------|
| لوگوی سایت | لوگوی اصلی بالای سایت |
| آیکون سایت (Favicon) | آیکون تب مرورگر |
| عنوان سایت | متن کنار لوگو |
| توضیحات سایت | زیرعنوان سایت |

### 📞 اطلاعات تماس
| تنظیم | کجا نمایش داده میشه | مقدار پیش‌فرض |
|-------|---------------------|---------------|
| شماره تلفن | پابرگ | `۰۲۱-۱۲۳۴۵۶۷۸` |
| ایمیل | پابرگ | `info@scarfstore.ir` |
| آدرس | پابرگ | خالی |
| ساعات کاری | پابرگ | `۹ صبح تا ۱۸` |

### 📱 شبکه‌های اجتماعی
| تنظیم | کجا نمایش داده میشه |
|-------|---------------------|
| لینک اینستاگرام | پابرگ (آیکون) |
| لینک تلگرام | پابرگ (آیکون) |
| لینک واتساپ | پابرگ (آیکون) |

### 📝 متن کپی‌رایت
| تنظیم | توضیح |
|-------|-------|
| متن کپی‌رایت | متن انتهای پابرگ. اگه خالی باشه: `تمام حقوق محفوظ است © سال جاری` |

---

## نحوه تغییر

1. از پیشخوان وردپرس برو به **نمایش ← سفارشی‌ساز**
2. روی هر بخش کلیک کن
3. مقادیر رو تغییر بده
4. **ذخیره و انتشار** رو بزن

---

## تغییر رنگ‌ها از کد

اگه میخوای رنگ‌های پیش‌فرض رو عوض کنی (نه از سفارشی‌ساز)، فایل `assets/css/main.css` رو ویرایش کن:

```css
:root {
    --scarf-color-primary: #d83f5f;    /* رنگ اصلی */
    --scarf-color-primary-hover: #c93452; /* رنگ هاور */
    --scarf-color-secondary: #19bfd3;  /* رنگ ثانویه */
}
```

**نکته:** رنگ‌های CSS custom properties روی تمام سایت اعمال میشن. فقط مقادیر `:root` رو عوض کن.
