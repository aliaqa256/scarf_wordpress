# راهنمای WooCommerce

پوسته Scarf از WooCommerce کاملاً پشتیبانی میکنه. شخصی‌سازی‌ها از طریق hook‌ها اعمال شدن (نه override فایل‌های الگو).

## شخصی‌سازی‌های انجام شده

### صفحه فروشگاه
- کانتینر با `max-width` و `margin-inline: auto` برای جلوگیری از چسبیدن محتوا به کناره‌ها
- گرید محصولات ۴ ستونه در دسکتاپ، ۲ ستونه در موبایل
- کارت‌های محصول با گوشه‌های گرد و سایه ملایم
- نمایش قیمت اصلی و تخفیف
- دکمه افزودن به سبد خرید

### سبد خرید AJAX
- آپدیت خودکار شمارنده سبد خرید بدون رفرش صفحه
- انیمیشن ملایم روی تغییر تعداد

### هدر
- آیکون سبد خرید با شمارنده
- لینک حساب کاربری

## نحوه تغییر استایل محصولات

### تغییر تعداد ستون‌ها
فایل `assets/css/woocommerce.css` رو ویرایش کن:

```css
/* دسکتاپ: ۳ ستون به جای ۴ */
.products {
    grid-template-columns: repeat(3, 1fr);
}
```

### تغییر استایل کارت محصول
```css
.product {
    border-radius: var(--scarf-radius-md);
    background: var(--scarf-color-surface);
    box-shadow: var(--scarf-shadow-sm);
}
```

### تغییر رنگ دکمه افزودن به سبد
```css
.button.ajax_add_to_cart,
.woocommerce button.button.alt {
    background-color: var(--scarf-color-primary);
    border-radius: var(--scarf-radius-pill);
}
```

## نکات مهم

### تعداد محصولات در هر صفحه
از پیشخوان وردپرس برو به **ووکامرس ← پیکربندی ← نمایش** و تعداد محصولات هر صفحه رو تنظیم کن.

### حلقه محصولات در Gutenberg
برای نمایش خودکار محصولات (جدیدترین، پرفروش، تخفیف‌دار) از بلوک‌های WooCommerce در ویرایشگر استفاده کن:
1. بلوک **«محصولات»** رو اضافه کن
2. نوع نمایش رو انتخاب کن (جدیدترین، پرفروش، و...)
3. تعداد ستون‌ها و ردیف‌ها رو تنظیم کن
