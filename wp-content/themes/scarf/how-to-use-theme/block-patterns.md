# راهنمای الگوهای Gutenberg (Block Patterns)

پوسته Scarf دارای ۷ الگوی آماده است که طراح میتونه در هر برگه یا نوشته‌ای استفاده کنه.

## نحوه استفاده

1. وارد ویرایشگر وردپرس شو (برگه جدید یا ویرایش برگه موجود)
2. روی آیکون **درج کننده بلوک** (خط‌های افقی بالا سمت راست) کلیک کن
3. تب **الگوها** رو انتخاب کن
4. دسته‌بندی مورد نظر رو انتخاب کن یا از **«همه الگوها را کاوش نمایید»** استفاده کن
5. روی الگو کلیک کن تا به برگه اضافه بشه
6. متن‌ها، تصاویر و لینک‌ها رو ویرایش کن

---

## دسته‌بندی‌ها

### 🎨 قالب شال (scarf)
تمام الگوهای اختصاصی پوسته در این دسته‌بندی قرار دارن.

### 🔥 بنر هیرو (scarf-hero)
الگوهای بنر اصلی بالای صفحه.

### 🎯 دکمه اقدام (scarf-cta)
الگوهای بنر تبلیغاتی و CTA.

---

## الگوها

### ۱. بنر هیرو (Hero Banner)
| | |
|---|---|
| **Slug** | `scarf/hero-banner` |
| **کجا استفاده بشه** | بالای صفحه اصلی، لندینگ پیج، صفحه فروش ویژه |
| **ساختار** | ۲ ستون: متن + تصویر |
| **محتوا** | عنوان اصلی، توضیحات، دکمه CTA |
| **نحوه ویرایش** | عنوان رو عوض کن، تصویر محصول رو جایگزین کن، لینک دکمه رو تنظیم کن |

**نمونه کاربرد:**
- صفحه اصلی: «جدیدترین شال و روسری‌ها»
- صفحه فروش ویژه: «تخفیف‌های تابستانه»

---

### ۲. بنر اقدام (CTA Banner)
| | |
|---|---|
| **Slug** | `scarf/cta-banner` |
| **کجا استفاده بشه** | بین بخش‌های صفحه، انتهای مقاله، صفحه محصول |
| **ساختار** | بنر تمام‌عرض با پس‌زمینه رنگی |
| **محتوا** | عنوان تبلیغاتی، توضیحات، دکمه CTA |
| **رنگ پیش‌فرض** | `#d83f5f` (رنگ اصلی سایت) |

**نمونه کاربرد:**
- «تخفیف ویژه تا ۳۰٪ — فرصت محدود»
- «عضویت در باشگاه مشتریان»

---

### ۳. نمادهای اعتماد (Trust Badges)
| | |
|---|---|
| **Slug** | `scarf/trust-badges` |
| **کجا استفاده بشه** | بالای صفحه محصول، انتهای صفحه اصلی، صفحه سبد خرید |
| **ساختار** | ۴ آیکون در یک ردیف |
| **محتوا** | ارسال سریع، ضمانت بازگشت، پرداخت امن، پشتیبانی خرید |

**نکته:** متن‌ها قابل تغییرن. میتونی آیکون‌ها رو هم عوض کنی.

---

### ۴. گرید دسته‌بندی (Category Grid)
| | |
|---|---|
| **Slug** | `scarf/category-grid` |
| **کجا استفاده بشه** | صفحه اصلی، صفحه فروشگاه، لندینگ پیج |
| **ساختار** | ۴ کارت در یک ردیف |
| **محتوا** | ۴ دسته‌بندی: شال، روسری، شال مجلسی، روسری نخی |

**نحوه ویرایش:**
- عنوان هر کارت رو عوض کن
- تصویر پس‌زمینه اضافه کن
- لینک هر کارت رو به دسته‌بندی مربوطه وصل کن

---

### ۵. گرید محصولات (Product Showcase)
| | |
|---|---|
| **Slug** | `scarf/product-showcase` |
| **کجا استفاده بشه** | صفحه اصلی، صفحه فروشگاه |
| **ساختار** | عنوان + لینک «مشاهده همه» + ۴ کارت محصول |
| **محتوا** | تصویر، نام محصول، قیمت |

**نکته:** این یک الگوی static هست. برای نمایش خودکار محصولات واقعی از بلوک **حلقه کوئری** استفاده کن.

---

### ۶. دو ستون — متن + تصویر (Two Column Split)
| | |
|---|---|
| **Slug** | `scarf/two-column-split` |
| **کجا استفاده بشه** | صفحه درباره ما، صفحه مقاله، صفحه معرفی محصول |
| **ساختار** | ۲ ستون برابر: متن در سمت راست + تصویر در سمت چپ |
| **محتوا** | عنوان، توضیحات، دکمه CTA، تصویر |

**نمونه کاربرد:**
- «چرا ما رو انتخاب کنید؟»
- «معرفی مجموعه شال‌های مجلسی»

---

### ۷. خبرنامه (Newsletter)
| | |
|---|---|
| **Slug** | `scarf/newsletter` |
| **کجا استفاده بشه** | انتهای صفحه اصلی، انتهای مقاله، صفحه وبلاگ |
| **ساختار** | متن + دکمه عضویت |
| **محتوا** | عنوان «عضویت در خبرنامه»، توضیحات، دکمه |

**نکته:** برای فرم واقعی عضویت، بلوک فرم رو به یک افزونه خبرنامه (مثل Mailchimp) وصل کن.

## نحوه تغییر الگوها

### تغییر رنگ پس‌زمینه بنرها
1. الگو رو اضافه کن
2. روی گروه (group) کلیک کن
3. در پنل سمت چپ، بخش **رنگ** رو باز کن
4. رنگ پس‌زمینه رو تغییر بده

### تغییر متن‌ها
- روی هر متن کلیک کن و مستقیماً ویرایش کن
- همه متن‌ها با فونت **Vazirmatn** نمایش داده میشن

### تغییر تصاویر
- روی تصویر کلیک کن
- آیکون **تغییر تصویر** رو بزن
- تصویر جدید رو آپلود کن

### تغییر لینک دکمه‌ها
- روی دکمه کلیک کن
- در نوار ابزار بالا، آیکون **لینک** رو بزن
- URL مقصد رو وارد کن

---

## اضافه کردن الگوی جدید

برای اضافه کردن الگوی جدید، فایل `inc/block-patterns.php` رو ویرایش کن:

```php
register_block_pattern( 'scarf/my-new-pattern', array(
    'title'      => __( 'عنوان الگو', 'scarf' ),
    'categories' => array( 'scarf' ),
    'content'    => '<!-- wp:group -->...<!-- /wp:group -->',
) );
```

**نکته:** محتوای `content` باید به فرمت block markup وردپرس باشه.
