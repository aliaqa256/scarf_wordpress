# خلاصه سریع تغییرات پوسته Scarf

## ✅ Phase A: رفع باگ‌ها
- **فیکس کانتینر صفحه فروشگاه**: اضافه کردن حاشیه و فاصله مناسب
- **AJAX سبد خرید**: آپدیت خودکار شمارنده سبد خرید بدون رفرش صفحه

## ✅ Phase B: سفارشی‌ساز (Customizer)
- اضافه کردن تنظیمات رنگ‌ها (اصلی، ثانویه، متن، پس‌زمینه)
- پشتیبانی از لوگوی سفارشی
- اضافه کردن لینک‌های شبکه اجتماعی

## ✅ Phase C: ابزارک‌ها
- اضافه کردن فیلترهای محصولات (قیمت، رنگ، برند، سایز)
- بهبود نوار کناری صفحات فروشگاه

## ✅ Phase D: الگوهای بلوک (Block Patterns)
- **۷ الگوی آماده** برای صفحه‌ساز گوتنبرگ
- **۳ دسته الگو**: قالب شال، بنر هیرو، دکمه اقدام
- الگوها در ویرایشگر گوتنبرگ قابل استفاده هستند

### لیست الگوها:
1. بنر هیرو
2. بنر اقدام (CTA)
3. نمادهای اعتماد
4. گرید دسته‌بندی
5. گرید محصولات
6. دو ستون — متن + تصویر
7. خبرنامه

---

## نحوه استفاده سریع:

### اضافه کردن الگو به صفحه:
1. در ویرایشگر گوتنبرگ روی **⊕** کلیک کنید
2. تب **الگوها** را انتخاب کنید
3. دسته **قالب شال** را پیدا کنید
4. روی الگوی مورد نظر کلیک کنید

### تغییر رنگ‌ها:
1. **نمایش → سفارشی‌ساز**
2. رنگ‌ها را تغییر دهید
3. انتشار را بزنید

### اضافه کردن فیلتر به فروشگاه:
1. **نمایش → ابزارکها**
2. نوار کناری فروشگاه را انتخاب کنید
3. ابزارک‌های فیلتر را اضافه کنید
