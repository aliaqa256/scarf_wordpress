# خلاصه سریع پوسته Scarf

## وضعیت فعلی

پوسته Scarf یک قالب حرفهای وردپرس برای فروشگاه شال و روسری با پشتیبانی کامل از WooCommerce و RTL فارسی است.

---

## ✅ قابلیتهای پیادهسازی شده

### قالب و ساختار
- ساختار استاندارد وردپرس با `functions.php`، `header.php`، `footer.php`
- سیستم طراحی با CSS Custom Properties (رنگ، فاصله، سایه، شعاع)
- RTL-first و فارسی اول
- `theme.json` با پالت رنگ کامل، اندازه فونت، فاصله، و الگوی سایه

### سفارشیساز (Customizer)
- **۱۷ رنگ قابل تنظیم** — اصلی، ثانویه، لهجه، متن، پسزمینه، تخفیف، موفقیت، هشدار، خطا
- **تایپوگرافی** — انتخاب فونت و اندازه عناوین
- **هدر** — هدر چسبنده، نمایش/مخفی جستجو و حساب کاربری
- **بنر اصلی** — عنوان، توضیحات، دکمه CTA، رنگ پسزمینه
- **پابرگ** — متن کپیرایت، لینک شبکههای اجتماعی
- **اطلاعات تماس** — تلفن، ایمیل، آدرس، ساعات
- **پیشنمایش زنده** در سفارشیساز

### ابزارکها (Widget Areas)
- **۴ ستون فوتر** — قابل مدیریت از بخش ابزارکها
- **سایدبار فروشگاه** — فیلترها و ناوبری محصولات
- **بالای/پایین صفحه اصلی** — قرار دادن ویجت بین بخشهای صفحه

### الگوهای بلوک (Block Patterns)
- **۱۶ الگوی آماده** در ۵ دسته
- بنرهای هیرو، بنرهای CTA، گرید محصولات، گرید دستهها، بخش اعتماد
- قابل استفاده در ویرایشگر گوتنبرگ

### صفحه اصلی
- بنر اصلی (Hero) با CTA
- دستهبندیها (شال، روسری، مجلسی، نخی، تخفیفدار)
- پیشنهاد ویژه (محصولات تخفیفدار)
- محصولات جدید
- پرفروشترینها
- نمادهای اعتماد (ارسال سریع، ضمانت بازگشت، پرداخت امن، پشتیبانی)

### WooCommerce
- کارت محصول با حلقه hooks (بدون override قالب)
- بج تخفیف درصدی و بج ناموجود
- صفحه آرشیو با سایدبار + دکمه فیلتر موبایل
- صفحه محصول تکی با انتخاب تنوع
- سبد خرید و پرداخت کامل با CSS
- آپدیت AJAX شمارنده سبد خرید

### سایر
- صفحه اصلی Ultimate Member (ورود، ثبتنام، حساب کاربری)
- `screenshot.png` برای نمایش در بخش پوستهها
- مستندات `how-to-use-theme/` شامل ۹ فایل راهنما

## نحوه استفاده سریع

### تغییر رنگها:
1. **نمایش → سفارشیساز → تنظیمات قالب شال → رنگها**
2. رنگها را تغییر دهید (پیشنمایش زنده)
3. **ذخیره و انتشار**

### اضافه کردن الگو به صفحه:
1. در ویرایشگر گوتنبرگ روی **⊕** کلیک کنید
2. تب **الگوها** را انتخاب کنید
3. دسته **قالب شال** را پیدا کنید
4. روی الگوی مورد نظر کلیک کنید

### اضافه کردن فیلتر به فروشگاه:
1. **نمایش → ابزارکها**
2. سایدبار فروشگاه را انتخاب کنید
3. ابزارکهای فیلتر WooCommerce را اضافه کنید

### مدیریت محتوای فوتر:
1. **نمایش → ابزارکها**
2. یکی از ۴ ستون فوتر را انتخاب کنید
3. ابزارکهای مورد نظر را اضافه کنید

## فایلهای اصلی

| فایل | توضیح |
|------|-------|
| `functions.php` | ثبت ویجتها، enqueue اسکریپتها، WooCommerce hooks |
| `inc/customizer.php` | ثبت تنظیمات سفارشیساز و خروجی CSS |
| `inc/woocommerce.php` | hooks و filterهای WooCommerce |
| `inc/block-patterns.php` | ثبت الگوهای بلوک |
| `inc/template-helpers.php` | توابع کمکی placeholder و عنوان بخش |
| `assets/css/main.css` | CSS اصلی با توکنهای طراحی |
| `assets/css/woocommerce.css` | CSS مخصوص WooCommerce |
| `assets/js/main.js` | منوی موبایل و فیلتر |
| `assets/js/customizer-preview.js` | پیشنمایش زنده سفارشیساز |
| `theme.json` | تنظیمات بلاک ادیتور و پالت رنگ |
