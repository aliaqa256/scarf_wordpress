# راهنمای الگوهای بلوک (Block Patterns)

## چرا الگوی بلوک؟

بدون الگو، طراح باید هر بخش را از صفر با بلوک‌های وردپرس بسازد.
با الگو، یک کلیک کافی‌ست — کل ساختار (ستون‌ها، رنگ‌ها، فاصله‌ها، استایل‌ها)
آماده می‌آید و فقط متن و تصویر عوض می‌شود.

## نحوه استفاده

1. برگه یا نوشته را در ویرایشگر Gutenberg باز کنید
2. روی دکمه `+` (درج کننده بلوک) در بالای صفحه کلیک کنید
3. تب `الگوها` را انتخاب کنید
4. دسته `قالب شال` را پیدا کنید
5. الگوی مورد نظر را انتخاب کنید
6. الگو در محتوا اضافه می‌شود
7. متن‌ها، تصاویر و لینک‌ها را ویرایش کنید

## الگوهای موجود

### بنر هیرو (`scarf/hero-banner`)
**ساختار:** دو ستون — ۵۵٪ متن + ۴۵٪ تصویر
**رنگ پس‌زمینه:** تیره (`#1a1a2e`)
**عناصر:** عنوان H1، پاراگراف توضیحات، دکمه CTA
**مناسب برای:** بنر اصلی صفحه اصلی، صفحه فرود

**نحوه ویرایش:**
- عنوان: روی متن «جدیدترین شال و روسری‌ها» کلیک → تایپ کنید
- توضیحات: پاراگراف زیر عنوان
- دکمه: روی دکمه کلیک → لینک و متن را عوض کنید
- تصویر: روی تصویر خالی کلیک → از کتابخانه رسانه تصویر انتخاب کنید

### بنر اقدام (`scarf/cta-banner`)
**ساختار:** یک ستون تمام‌عرض
**رنگ پس‌زمینه:** صورتی (`#d83f5f`)
**عناصر:** عنوان H2، پاراگراف، دکمه وسط‌چین
**مناسب برای:** بنر تخفیف، کمپین فروش، جشنواره

### نمادهای اعتماد (`scarf/trust-badges`)
**ساختار:** ۴ ستون افقی
**رنگ پس‌زمینه:** خاکستری روشن (`#f8f9fa`)
**عناصر:** ۴ آیکون ایموجی + متن
**مناسب برای:** پایین صفحه اصلی، پایین صفحه فرود، بعد از CTA

**نحوه ویرایش:**
- متن هر آیکون را عوض کنید
- برای تغییر آیکون: ایموجی را پاک → ایموجی جدید تایپ کنید

### گرید دسته‌بندی (`scarf/category-grid`)
**ساختار:** عنوان + ۴ ستون
**عناصر:** ۴ کارت با پس‌زمینه روشن و عنوان
**مناسب برای:** نمایش دسته‌بندی‌های اصلی

**نحوه ویرایش:**
- عنوان هر کارت را عوض کنید
- برای اضافه کردن تصویر: روی کارت کلیک → یک بلوک تصویر اضافه کنید

### گرید محصولات (`scarf/product-showcase`)
**ساختار:** عنوان + لینک «مشاهده همه» + ۴ ستون محصول
**عناصر:** تصویر محصول + نام + قیمت
**مناسب برای:** نمایش محصولات ویژه، پرفروش‌ها

**نحوه ویرایش:**
- عنوان: «محصولات ویژه» را عوض کنید
- لینک «مشاهده همه»: URL فروشگاه یا دسته‌بندی مورد نظر
- تصاویر: از کتابخانه رسانه انتخاب کنید
- نام و قیمت: متن را ویرایش کنید

### دو ستون — متن + تصویر (`scarf/two-column-split`)
**ساختار:** دو ستون مساوی — چپ متن + راست تصویر
**عناصر:** عنوان H2، پاراگراف، دکمه CTA، تصویر
**مناسب برای:** معرفی خدمات، درباره ما، محتوای ترکیبی

### خبرنامه (`scarf/newsletter`)
**ساختار:** دو ستون — ۶۰٪ متن + ۴۰٪ دکمه
**رنگ پس‌زمینه:** خاکستری روشن (`#f8f9fa`)
**مناسب برای:** عضویت خبرنامه، ثبت‌نام

## نکات مهم

- تمام الگوها **RTL** هستند (راست‌به‌چپ)
- فونت **Vazirmatn** روی همه المان‌ها اعمال شده
- رنگ‌ها از **پالت پوسته** پیروی می‌کنند
- گوشه‌ها **گرد** هستند (`border-radius: 999px` برای دکمه‌ها)
- الگوها در هر برگه، نوشته یا ویرایشگر سفارشی قابل استفاده هستند
