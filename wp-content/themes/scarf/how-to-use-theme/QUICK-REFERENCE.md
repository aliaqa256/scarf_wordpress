# کارت مرجع سریع — پوسته Scarf

## تغییر رنگ
`پیشخوان` → `نمایش` → `سفارشی‌سازی` → `رنگ‌های پوسته Scarf`

## نمایش/مخفی کردن المان‌ها
`سفارشی‌سازی` → `تنظیمات پوسته Scarf`

## اضافه کردن بخش به برگه
`درج کننده بلوک (+)` → `تب الگوها` → `قالب شال`

## تنظیم منو
`پیشخوان` → `نمایش` → `فهرست‌ها` → موقعیت: `menu-primary`

## ویجت‌های فروشگاه
`پیشخوان` → `نمایش` → `ابزارک‌ها` → `فیلترهای فروشگاه`

## لوگوی سایت
`سفارشی‌سازی` → `هویت سایت`

## الگوهای موجود

| الگو | کجا استفاده شود |
|------|-----------------|
| بنر هیرو | صفحه اصلی، درباره ما، صفحه فرود |
| بنر اقدام | صفحه تخفیف، کمپین‌های فروش |
| نمادهای اعتماد | پایین هر صفحه فرود |
| گرید دسته‌بندی | صفحه اصلی، صفحه فرود |
| گرید محصولات | صفحه اصلی، صفحه فرود |
| دو ستون | درباره ما، معرفی خدمات |
| خبرنامه | پایین هر صفحه |
