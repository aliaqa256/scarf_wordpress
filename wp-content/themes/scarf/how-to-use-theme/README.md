## 1. معرفی کلی
پوسته **Scarf** یک پوسته سفارشی وردپرس برای فروشگاه آنلاین شال و روسری است. این پوسته شامل:

- صفحه اصلی با بخش‌های از پیش طراحی شده
- ۷ الگوی بلوک آماده برای صفحه‌ساز گوتنبرگ
- سفارشی‌ساز رنگ‌ها، لوگو و فوتر
- پشتیبانی کامل از RTL و فارسی

---

## 2. ساختار فایل‌ها

```
scarf/
├── assets/css/main.css          ← استایل اصلی سایت
├── assets/css/woocommerce.css   ← استایل صفحات فروشگاه
├── assets/js/main.js            ← اسکریپت‌های جاوااسکریپت
├── inc/block-patterns.php        ← الگوهای بلوک گوتنبرگ
├── inc/customizer.php            ← تنظیمات سفارشی‌ساز
├── inc/woocommerce.php           ← تنظیمات ووکامرس
├── template-parts/
│   ├── hero-section.php          ← بنر هیرو صفحه اصلی
│   ├── section-categories.php    ← بخش دسته‌بندی محصولات
│   ├── section-new-arrivals.php  ← محصولات جدید
│   ├── section-best-sellers.php  ← پرفروش‌ها
│   ├── section-offers.php        ← پیشنهادات ویژه
│   ├── section-services.php      ← بخش خدمات (ارسال، ضمانت و...)
│   └── section-trust.php         ← نمادهای اعتماد
├── theme.json                    ← تنظیمات قالب گوتنبرگ
├── functions.php                 ← عملکرد اصلی پوسته
├── header.php                    ← هدر سایت
├── footer.php                    ← فوتر سایت
└── front-page.php                ← صفحه اصلی
```

## 3. الگوهای بلوک (Block Patterns)
> **این الگوها مهم‌ترین قابلیت برای طراحان هستند**

الگوهای بلوک به شما اجازه می‌دهند با یک کلیک بخش‌های آماده را به هر صفحه‌ای اضافه کنید.

### نحوه استفاده:
1. در ویرایشگر گوتنبرگ، روی **⊕ درج کننده بلوک** کلیک کنید
2. تب **الگوها** را انتخاب کنید
3. دسته **قالب شال** را پیدا کنید
4. روی الگوی مورد نظر کلیک کنید تا به صفحه اضافه شود

### الگوهای موجود:

| نام الگو | کاربرد | کجا استفاده کنیم |
|----------|--------|-----------------|
| **بنر هیرو** | بنر اصلی با عنوان + توضیح + دکمه | بالای صفحه اصلی، لندینگ پیج |
| **بنر اقدام** | بنر تمام‌عرض رنگی با CTA | بین بخش‌های سایت، کمپین‌های فروش |
| **نمادهای اعتماد** | ردیف ۴ نماد (ارسال، ضمانت، امنیت، پشتیبانی) | زیر بنر هیرو، قبل فوتر |
| **گرید دسته‌بندی** | ۴ کارت دسته‌بندی | صفحه اصلی، صفحه دسته‌بندی |
| **گرید محصولات** | ۴ کارت محصول با قیمت | صفحه اصلی، صفحه فروش ویژه |
| **دو ستون — متن + تصویر** | متن در یک طرف، تصویر در طرف دیگر | درباره ما، معرفی محصول |
| **خبرنامه** | فرم عضویت خبرنامه | قبل فوتر، صفحه تماس |

### مثال عملی:
می‌خواهید یک صفحه فروش ویژه بسازید:
1. صفحه جدید بسازید → **برگه‌ها → افزودن**
2. عنوان: **فروش ویژه تابستانه**
3. ⊕ کلیک کنید → تب الگوها → **قالب شال**
4. اول **بنر اقدام** را اضافه کنید
5. بعد **گرید محصولات** را اضافه کنید
6. در آخر **نمادهای اعتماد** را اضافه کنید

## 4. تنظیمات سفارشی‌ساز (Customizer)
> از مسیر **نمایش → سفارشی‌ساز** وارد شوید

### قابلیت‌های سفارشی‌ساز:
- **لوگوی سایت**: آپلود و تغییر لوگو
- **رنگ اصلی**: تغییر رنگ برند (دکمه‌ها، لینک‌ها، هایلایت‌ها)
- **رنگ ثانویه**: رنگ پس‌زمینه بنرها و بخش‌های ویژه
- **رنگ متن**: رنگ اصلی نوشته‌ها
- **رنگ پس‌زمینه**: رنگ کلی صفحه
- **آیکون‌های شبکه اجتماعی**: لینک‌های اینستاگرام، تلگرام و...

### نحوه استفاده:
1. **نمایش → سفارشی‌ساز** را باز کنید
2. هر بخش را تغییر دهید (پیش‌نمایش زنده نمایش داده می‌شود)
3. روی **انتشار** کلیک کنید تا تغییرات ذخیره شود

## 5. ابزارک‌ها (Widgets)
> از مسیر **نمایش → ابزارکها** وارد شوید

### نوار کناری فروشگاه:
ابزارک‌های زیر در نوار کناری صفحات فروشگاه قابل استفاده هستند:
- **فیلتر بر اساس قیمت**: فیلتر محصولات با رنج قیمتی
- **فیلتر بر اساس رنگ**: نمایش رنگ‌های موجود محصولات
- **فیلتر بر اساس برند**: فیلتر محصولات بر اساس برند
- **فیلتر بر اساس سایز**: فیلتر محصولات بر اساس سایز

### نحوه استفاده:
1. **نمایش → ابزارکها** را باز کنید
2. نوار کناری فروشگاه را انتخاب کنید
3. ابزارک‌های مورد نظر را با کشیدن و رها کردن اضافه کنید

## 6. ویرایش صفحه اصلی
صفحه اصلی از چند بخش تشکیل شده است. هر بخش یک **قالب بخش (template part)** است.

### بخش‌های صفحه اصلی:
1. **بنر هیرو**: عنوان اصلی + توضیح + دکمه خرید
2. **دسته‌بندی‌ها**: ۴ دسته‌بندی اصلی محصولات
3. **پیشنهادات ویژه**: محصولات تخفیف‌دار
4. **جدیدترین محصولات**: آخرین محصولات اضافه شده
5. **پرفروش‌ها**: محبوب‌ترین محصولات
6. **خدمات**: ارسال سریع، ضمانت بازگشت، پشتیبانی
7. **نمادهای اعتماد**: نمادهای اعتماد الکترونیکی

### نحوه ویرایش هر بخش:
هر بخش در فایل `template-parts/section-*.php` قرار دارد. برای ویرایش:
1. فایل مربوطه را باز کنید (مثلاً `template-parts/hero-section.php`)
2. متن‌ها و لینک‌ها را تغییر دهید
3. تصاویر را از مسیر `assets/images/` جایگزین کنید

### نکته مهم:
> متن‌های داخل تابع `esc_html__()` قابل ترجمه هستند. اگر می‌خواهید متن را عوض کنید، مقدار دوم را تغییر دهید (مثلاً `esc_html__('متن جدید', 'scarf')`).

## 7. تغییر رنگ‌ها و فونت

### رنگ‌های اصلی پوسته:
- **رنگ اصلی**: `#d83f5f` (صورتی/قرمز) — دکمه‌ها، لینک‌ها
- **رنگ پس‌زمینه**: `#f9f9fb` — پس‌زمینه کلی سایت
- **رنگ متن**: `#1a1a2e` — نوشته‌های اصلی
- **رنگ ثانویه**: `#6c757d` — نوشته‌های فرعی

### نحوه تغییر رنگ‌ها:
1. روش آسان: از **سفارشی‌ساز** استفاده کنید (بخش ۴)
2. روش حرفه‌ای: فایل `assets/css/main.css` را ویرایش کنید و مقادیر متغیرهای CSS را تغییر دهید:

```css
:root {
    --scarf-color-primary: #d83f5f;  /* ← این مقدار را عوض کنید */
    --scarf-color-text: #1a1a2e;     /* ← رنگ متن اصلی */
    --scarf-color-muted: #6c757d;    /* ← رنگ متن فرعی */
}
```

### فونت:
پوسته از فونت **Vazirmatn** استفاده می‌کند. برای تغییر فونت:
1. فونت جدید را در فایل `functions.php` اضافه کنید
2. کلاس‌های مربوطه را در `main.css` به‌روز کنید

## 8. مدیریت محتوا

### محصولات:
- **محصولات → همه محصولات**: لیست تمام محصولات
- **محصولات → افزودن محصول جدید**: اضافه کردن محصول جدید
- **محصولات → دسته‌بندیها**: مدیریت دسته‌بندی‌ها
- **محصولات → ویژگیها**: مدیریت ویژگی‌ها (رنگ، سایز و...)

### نوشته‌ها:
- **نوشتهها → همهٔ نوشتهها**: مقالات وبلاگ
- **نوشتهها → افزودن نوشته**: نوشتن مقاله جدید

### برگه‌ها:
- **برگهها → همهٔ برگهها**: صفحات ثابت (درباره ما، تماس با ما و...)
- **برگهها → افزودن برگه**: ساخت صفحه جدید

## 9. فایل‌های CSS

### فایل‌های استایل:
- `assets/css/main.css`: استایل‌های اصلی سایت (هدر، فوتر، صفحه اصلی)
- `assets/css/woocommerce.css`: استایل‌های اختصاصی صفحات فروشگاه

### نکات مهم:
1. **هرگز فایل‌های هسته وردپرس یا ووکامرس را ویرایش نکنید**
2. **فایل‌های CSS خود را در پوشه `assets/css/` ذخیره کنید**
3. **از متغیرهای CSS برای رنگ‌ها و فاصله‌ها استفاده کنید**
4. **تغییرات را در انتهای فایل اضافه کنید، نه وسط آن**

## سوالات متداول

**问我: چطوری یک صفحه جدید با الگوهای بلوک بسازم؟**
1. برگه‌ها → افزودن برگه
2. عنوان صفحه را وارد کنید
3. ⊕ → تب الگوها → دسته مورد نظر را انتخاب کنید
4. الگو را کلیک کنید تا اضافه شود
5. محتوا را ویرایش کنید

**问我: چطوری رنگ دکمه‌ها را عوض کنم؟**
1. نمایش → سفارشی‌ساز → رنگ‌ها
2. رنگ اصلی را تغییر دهید
3. انتشار را بزنید

**问我: الگوها در ویرایشگر نمایش داده نمی‌شوند؟**
1. مطمئن شوید پوسته Scarf فعال است
2. صفحه را رفرش کنید
3. اگر مشکل ادامه داشت، از **ابزارها → سلامت سایت** استفاده کنید
